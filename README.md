# Employee Analytics Dashboard | Power BI

Interactive HR dashboard tracking 1,000 employees across 6 regions and 4 industries from 2022-2026.

**Key Features**
- **Executive KPIs**: Headcount, Avg Salary $138.6K, Avg Performance 3.01, Bonus 7.37%
- **Workforce Breakdown**: By Region, Employment Type, Gender 53.4% F / 46.5% M, Remote 38.47%
- **Trends**: Annual Salary + Avg Salary per Employee 2022-2026
- **Deep Dives**: Department by WorkSetting, Performance by Industry, Company-level headcount
- **Filters**: WorkYear, Industry, Region, Gender, EmploymentType
